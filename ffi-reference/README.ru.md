# Сохранённая документация cffi-lua

Эти четыре страницы — оригинальная документация upstream, на английском:

- [Введение](introduction.md).
- [API](api.md).
- [Семантика, преобразования и особенности совместимости](semantics.md).
- [Синтаксис C-деклараций](syntax.md).

Источник: `https://github.com/q66/cffi-lua`, commit
`2621884230c9072ad77f7379609b74c9d6dbeb86`.
Файлы скопированы без изменения содержимого из сохранённого upstream.
Лицензия MIT: [COPYING.md](COPYING.md).

Особенности нашей интеграции описаны по-русски в [FFI.ru.md](../FFI.ru.md)
и [FFI_DETAILS.ru.md](../FFI_DETAILS.ru.md): статическое подключение к
Lua 5.5, глобальный `ffi`, ограниченный `require`, UTF-8 пути загрузки DLL,
контекст callbacks и ограничения API скита. Upstream не описывает эти
добавления и не является инструкцией по установке отдельного LuaRocks-пакета
в скит. Использовать LuaRocks для встроенного модуля пользователю не нужно.
